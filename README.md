# Portfolio — Nguyễn Quốc Khánh

Website portfolio cá nhân, xây bằng HTML5 + CSS3 + JavaScript thuần, có nền hiệu ứng mạng lưới hạt (particle network) dựng bằng Three.js, và nút chuyển giao diện sáng/tối.
